# تقويمي (Taqwimi)

رفيقك الأكاديمي الذكي لصياغة وتحكيم الأسئلة الاختبارية — منصة أكاديمية ذكية مبنية بـ React وTypeScript، تُوظّف نموذج Gemini من Google لمساعدة أعضاء هيئة التدريس والخبراء التربويين على:

- **توليد** بنود اختبارية (اختيار من متعدد، صواب وخطأ، إكمال الفراغ، مزاوجة، مقالي، اختيار متعدد الإجابات، ترتيب، وإكمال الرسوم التوضيحية) مباشرة من محتوى المقرر العلمي.
- **تحسين وتحكيم** صياغة الأسئلة لغويًا وتربويًا، وفق ضوابط كل نوع سؤال.
- **تقييم سيكومتري شامل** يراجع التوافق مع تصنيف بلوم، الصدق العلمي، فاعلية المشتتات، والعدالة.
- **أدوات مساندة**: جدول مواصفات الاختبار، تحليل الأداء السيكومتري بعد التطبيق (معامل السهولة p ومعامل التمييز D)، وتصدير الاختبار إلى Word أو طباعته مباشرة.

مبني بدعم كامل للغة العربية واتجاه الكتابة من اليمين إلى اليسار (RTL)، مع إمكانية التبديل إلى الإنجليزية.

## التشغيل محليًا (Run locally)

**المتطلبات (Prerequisites):** Node.js 18 أو أحدث.

1. تثبيت الاعتماديات:
   ```bash
   npm install
   ```
2. إنشاء ملف `.env` بناءً على `.env.example` وتعيين مفتاح Gemini الخاص بك:
   ```bash
   cp .env.example .env
   # ثم افتح .env وضع GEMINI_API_KEY الحقيقي
   ```
3. تشغيل بيئة التطوير:
   ```bash
   npm run dev
   ```
4. للبناء الإنتاجي:
   ```bash
   npm run build
   npm start
   ```

## البنية التقنية

- **الواجهة:** React 19 + TypeScript + Tailwind CSS v4، مع خطي Cairo وEl Messiri.
- **الخادم:** Express.js يتوسط الواجهة ونموذج Gemini (توليد الأسئلة، التحكيم، واستخراج النصوص من الملفات).
- **أدوات إضافية:** مكتبة `docx` لتصدير الاختبار كملف Word مباشرة من المتصفح، وRecharts للرسوم البيانية.

## هيكل المشروع

```
src/
  components/     # مكونات الواجهة (التوليد، التحسين، التحكيم، الأدوات المساندة...)
  App.tsx         # المكوّن الرئيسي وبوابة تسجيل الدخول
  translations.ts # نصوص الواجهة بالعربية والإنجليزية
  types.ts        # تعريفات TypeScript المشتركة
server.ts         # خادم Express ونقاط اتصال Gemini
```

## ملاحظة أمنية

لا تقم أبدًا برفع مفتاح `GEMINI_API_KEY` الحقيقي إلى GitHub. ملف `.gitignore` في هذا المستودع يستبعد `.env*` تلقائيًا (باستثناء `.env.example`).
